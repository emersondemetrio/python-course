# Module 02: Decisions and loops

Until now, your programs ran every line once, from top to bottom. In this module they start to **choose** (do this or that) and to **repeat** (do this for every item). You will also learn **lists**, the most common way to keep many values together.

These three ideas together are what make a program feel "smart": look at each item, decide something about it, and act.

## What you will learn

- How Python decides between paths with `if`, `elif` and `else`
- How to compare values and combine conditions with `and`, `or` and `not`
- How to keep many values in a list, read them, add to them and remove from them
- How to repeat actions with `for` and `while`
- How to count and add things up inside a loop

## How to study this module

1. Read a section, then type the examples yourself in Cursor. Do not copy and paste. Typing is how your fingers and eyes learn the shapes of the code.
2. Run each example and compare your output with the one in the file.
3. Try each exercise **before** opening the answer. If you get stuck for more than 10 minutes, open the hint, not the answer.
4. Copy the **Recap** of each file into your own notes, in your own words.
