# Extra exercises

> **In one sentence:** standalone exercises to do on your own, between classes, with instructions and hints but **no ready-made answers**.

## What this is

Each file is a small, self-contained challenge. You don't need to do them in order, but they are roughly sorted from easiest to hardest. Right now they only use what was covered in the first classes: the terminal, variables, text, lists, `for`, `if`, functions and files.

There are no answers on purpose. The goal is to practice getting unstuck by yourself: reading the error, trying again, using a hint. If you are stuck for real, bring the exercise to the next class.

## How to work

1. In the terminal, go to your `Projects` folder and create a folder `extra` for these exercises. Open it in the editor with `cursor .`.
2. Create **one `.py` file per exercise**, with the name the exercise suggests.
3. Write a little, save (`Ctrl+S`), run (`python file.py`), repeat. Don't write everything before running.
4. When you see an error, read it from the bottom up: what went wrong, and on which line.
5. Open the hints **one at a time**, and only after trying for a few minutes.
6. Compare your output with **What it should look like**. It must match exactly, line by line.
7. Go through **Check yourself**. Then try **Go further** if you want more.
8. Write in your notes, in your own words, one thing you learned or got stuck on.
