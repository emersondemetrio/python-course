# Module 01: The building blocks

Every program, no matter how big, is built from a few small pieces: **values**, **names** that hold those values, and **built-in tools** that Python gives you for free. This module is about those pieces.

You have already used most of them in class. Here you will see them again, slowly, with names for each idea and a lot of practice.

## Goals

By the end of this module you will be able to:

- Store values in variables and predict what a variable holds after it changes.
- Tell the difference between `int`, `float`, `str` and `bool`, and convert between them.
- Build sentences with `+` and with f-strings, and know when each one breaks.
- Use the most common built-in functions: `print`, `input`, `len`, `type`, `int`, `float`, `str`, `round` and `enumerate`.
- Explain the difference between a function's **name** (`len`) and a function **call** (`len(x)`).

## How to run the examples

1. Open your `Projects` folder in Cursor (`cursor .` from the terminal).
2. Create a file such as `module01.py`.
3. Paste or type the example, save with `Ctrl+S`, and run it:

```powershell
PS C:\Users\you\Projects> python module01.py
```

Typing the examples yourself, instead of pasting them, helps your hands and eyes learn the syntax.
