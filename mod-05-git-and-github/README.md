# Module 05: Git and GitHub

You now have real programs, like the notes app from module 04. Programs change all the time: you add a feature, break something, fix it, try an idea, regret it. In this module you will learn to keep the **history** of your project, so you can always see what changed and go back if needed, and to put your project **online** on GitHub, where others can see it and work with you.

You will also learn Markdown, the simple text format used for README files, notes and this course itself.

## What you will learn

- What version control is and why every programmer uses it
- The everyday Git commands: `init`, `status`, `add`, `commit`, `log`, `diff`
- How to ignore files you do not want to save in the history
- What GitHub is, and how to send (`push`) and receive (`pull`, `clone`) your project
- How to write clear README files and notes in Markdown

## Files in this module (read them in order)

1. [git-basics.md](git-basics.md): saving the history of your project on your computer
2. [github.md](github.md): putting your project online and working with others
3. [markdown.md](markdown.md): writing nice-looking text files

Estimated time: 2 to 3 study sessions of about 1 hour. Most of the practice here happens in the **terminal**, not in Python.

## Before you start

- You should be comfortable moving around in the terminal with `pwd`, `ls` and `cd` (module 00).
- You need a GitHub account (free) at [github.com](https://github.com).
- Have the `notes` project from module 04 ready. You will turn it into your first repository.
